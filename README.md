# The Return on Sanity: Financial Simulations

Code repository for the "Return on Sanity" article series.

**Repository Contents:**

1. **`fragility_test.py` (Part I)**: 
   A simulation of "Sequence Risk." It compares a linear 7% return model against a reality where a market shock happens early.

2. **`volatility_simulation.py` (Part II)**: 
   A simulation of the "Volvo Paradox." It demonstrates the Ergodicity Gap—showing how betting 100% of equity on a positive-edge game leads to ruin.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run Part I: `python fragility_test.py`
3. Run Part II: `python volatility_simulation.py`
